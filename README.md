# LINA OS

An optional Linux distribution built around [LINA](https://github.com/lina-system/lina) and the [LINA app](https://github.com/lina-system/lina-app), composing their released artifacts with an OS layer for install, update and recovery. Exploration: nothing here is needed to use LINA, and this repository holds no code yet.
